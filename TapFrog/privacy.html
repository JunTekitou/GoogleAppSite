プライバシーポリシー

最終更新日: 2026年4月11日

本プライバシーポリシーは、「TapFrog」（以下、「本アプリ」）の利用に際して、開発者が取得するユーザー情報とその取り扱いについて説明するものです。

1. 取得する情報と利用目的

本アプリは、その機能を提供するために、以下の情報をユーザーのデバイス内で取得・利用しますが、これらの情報を外部に送信することはありません。

  • AccessibilityService API（ユーザー補助サービスAPI）を通じてアクセスする情報
    本アプリは、本APIを以下の目的で利用する。これらはユーザーがアプリのメイン機能を実行するために不可欠なものである。
    • 画面操作の自動実行（ジェスチャーの実行）: ユーザーが事前に設定した「タップ」「スワイプ」などの操作を、ユーザーに代わって正確なタイミングで実行するために利用する。
    • 画面情報の参照（コンテンツの読み取り）: 設定された座標の確認や、アプリが正しく動作するための画面状態の把握に利用する場合がある。
    重要: 本アプリは、AccessibilityService APIを使用して、個人情報、機密情報、またはユーザーの入力内容を収集、記録、保存、あるいは外部へ送信することは一切ない。
  • ユーザーが作成した設定データ
    ユーザーが作成した操作アシスト（アクションポイントの座標、タイミング、順序、付箋メモなど）は、ユーザーのデバイス内にのみ保存される。これらのデータが開発者や第三者に送信されることはない。

2. 情報の第三者への提供

本アプリは、ユーザーの情報を外部に送信しないため、第三者にユーザーの情報を提供することはない。

3. データの保存期間と削除

本アプリが取得・保存する設定データは、ユーザーのデバイス内にのみ保存される。これらのデータは、ユーザーが本アプリをアンインストールすることで、デバイス内から完全に削除される。

4. セキュリティ

本アプリで扱うすべてのデータは、ユーザーのデバイス内で完結しており、Android OSが提供するセキュリティ機構によって保護されている。

Privacy Policy

Last updated: April 11, 2026

This Privacy Policy describes how "TapFrog" (hereinafter referred to as "the App") handles user information.

1. Information Collection and Purpose

The App accesses and uses the following information within the user's device to provide its features, but does not transmit this information externally.

  • AccessibilityService API
    The App uses this API for the following purposes, which are essential for the core functionality:
    • Performing Gestures: To perform "tap" and "swipe" operations at the precise timing as pre-configured by the user.
    • Reading Screen Content: May be used to confirm coordinates or understand the screen state for the App to function correctly.
    IMPORTANT: The App does NOT use the AccessibilityService API to collect, record, store, or transmit any personal or sensitive information, or user input.
  • User-Created Data
    Assist settings (coordinates, timing, order, sticky notes) are stored only on the user's device and are never sent to the developer or any third party.

2. Third-Party Disclosure

The App does not transmit user information externally, and therefore does not provide information to third parties.

3. Data Retention and Deletion

All data is stored locally. Data is completely removed from the device when the user uninstalls the App.

4. Security

All data is contained within the device and protected by Android OS security mechanisms.
